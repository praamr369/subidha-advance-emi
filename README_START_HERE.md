2. Copy Template A from MASTER guide

   - API function name
   - Status/filter options
   - Table columns definition
4. Run `npm run build`
5. Test in browser

**Time: 30 mins**

### **For Hub Pages (Template B)**
1. Open Template B from MASTER guide
2. Replace:
   - Data loading functions
   - Hub card definitions (title, href, icon)
3. Keep existing card components
4. Run `npm run build`

**Time: 45-60 mins**

1. Keep existing form structure
2. Update styling to modern Tailwind:
   - Input classes
   - Button classes
   - Error/success styling

4. Run `npm run build`

**Time: 30-45 mins**
