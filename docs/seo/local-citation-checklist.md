# Local Citation Checklist — Subidha Furniture (owner tasks)

A "citation" is any online listing of your business Name, Address, Phone (NAP).
Google trusts a business more when NAP is **identical** everywhere. Inconsistent
addresses/phones hurt local ranking.

## The single source of truth

Decide one exact form and reuse it verbatim everywhere:

- **Name:** Subidha Furniture
- **Address:** <exact showroom address, Asansol, West Bengal, PIN>
- **Phone:** <exact business phone>
- **Website:** https://subidhafurnitureasansol.com
- **Hours:** <exact opening hours>

Fill the same values in the admin → Business Setup → Public Site profile so the
website matches.

## Where to list (only where you actually have/maintain an account)

| Platform | Action | NAP must match |
|---|---|---|
| Google Business Profile | Primary listing — see GBP checklist | Yes |
| Facebook Page | Add address, phone, hours, website link | Yes |
| Instagram profile | Add website link, city in bio | Yes |
| YouTube channel | Add website link in About (if used) | Yes |
| Justdial | Claim/verify listing (if used) | Yes |
| IndiaMART | Business profile (if used) | Yes |
| Local/regional directories | List only reputable ones | Yes |

## Rules

- Same **Name, Address, Phone** on every platform — no abbreviations on one and
  full form on another.
- Same **website URL** everywhere: `https://subidhafurnitureasansol.com`.
- Same **opening hours** everywhere; update all when they change.
- Do not create duplicate listings for the same location.
- Only link social accounts you actually maintain and respond on.
- When the showroom address or phone changes, update **every** listing.
