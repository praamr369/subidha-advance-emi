BACKEND GAPS IDENTIFIED (READY TO FIX)
================================================================================

1. PAGINATION
   Problem: Large lists load all rows
   Impact: Performance degradation
   Fix: Add DRF pagination to list views
   Complexity: LOW (1 line per view)

2. STATS ENDPOINTS
   Problem: Frontend calculates stats from full list (N+1)
   Impact: Poor performance
   Fix: Create /api/v1/admin/crm/stats/ endpoint
   Complexity: MEDIUM

3. FILTER/SEARCH CONSISTENCY
   Problem: Query params vary by endpoint
   Impact: Harder to implement uniform UI
   Fix: Standardize to q, status, created_after, etc.
   Complexity: MEDIUM

4. N+1 QUERY PROBLEMS
   Problem: Eager loading not used
   Impact: Slow page loads
   Fix: Add select_related() + prefetch_related()
   Complexity: MEDIUM

5. AUDIT LOGGING
   Problem: No trail for state changes
   Impact: Compliance gap
   Fix: Add AuditLog entries to endpoints
   Complexity: MEDIUM

6. BULK OPERATIONS
   Problem: User must operate one item at a time
   Impact: Poor UX for high-volume work
   Fix: Add batch endpoints for common operations
   Complexity: MEDIUM
