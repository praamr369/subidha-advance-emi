UNIFIED PATTERN NOW APPLIED
================================================================================

All 5 CRM profile pages follow this structure:

  <ERPPageShell
    eyebrow="Module Name"
    title="Entity Type"
    subtitle="Description"
    breadcrumbs={[...]}
    actions={[...]}  // Route to downstream modules
    stats={ProfileStatsCalculator.calculate*(...)}  // Centralized KPIs
    statusBadge={{ label: "...", tone: "info" }}
  >
    <div className="space-y-6">
      <ProfileToolbar {...} />
      <ProfileTable {...} />
      {/* Contextual sections only (CSV import, readiness) */}
    </div>
  </ERPPageShell>

Principles Enforced:
  1. No duplicate KPIs - stats in header only
  2. Unified toolbar - ProfileToolbar component
  3. Consistent table rendering - ProfileTable wrapper
  4. Module clarity - clear navigation to downstream modules
  5. Workflow preservation - contextual sections intact

INTEGRATION GUIDE FOR FUTURE PAGES
================================================================================

To apply this pattern to other profile pages:

Step 1: Import components
  import { ProfileStatsCalculator, ProfileToolbar, ProfileTable }
    from "@/components/crm-workbench";

Step 2: Calculate header stats
  const headerStats = useMemo(
    () => ProfileStatsCalculator.calculateCustomerStats({
      totalCount: count,
      activeCount: activeRows.length,
      pendingKycCount: pendingRows.length,
      activeSubscriptionsCount: subscriptions.length,
      loading,
    }),
    [count, activeRows, pendingRows, subscriptions, loading]
  );

Step 3: Use ProfileToolbar (optional)
  <ProfileToolbar
    searchValue={query}
    onSearchChange={setQuery}
    onRefresh={loadData}
    filters={[...]}
    filterValues={{}}
    onFilterChange={handler}
    onReset={handler}
  />

Step 4: Wrap table with ProfileTable (optional)
  <ProfileTable
    title="Registry Name"
    data={rows}
    columns={[...]}
    loading={loading}
    error={error}
    onRetry={reload}
  />

Step 5: Verify TypeScript
  npx tsc --noEmit -p tsconfig.json

Step 6: Test in browser
  npm run dev
  Navigate to page and verify
